# Career Universe

Companion inteligente para saves do EA Sports FC.

## Objetivo

Transformar o Modo Carreira em um universo persistente, com histórico de temporadas, ligas, jogadores, transferências, títulos, recordes e desafios.

## V1

- PWA instalável no celular
- Tela inicial do save
- Histórico de ligas e títulos
- História de jogadores / Hall da Fama
- Mercado de transferências
- Desafios aleatórios de janela
- Importação de screenshots (interface pronta; leitura por IA entra na próxima etapa)

## Próximos passos

- Banco de dados por save
- Criar/resetar universos
- Upload real de imagens
- Extração por IA com confirmação antes de salvar
- Estatísticas e recordes automáticos
- Assistente que consulta o histórico do save

Projeto inicial criado a partir do save Super Liga do Grêmio.
